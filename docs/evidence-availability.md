The numeric bootstrap matrix contains indices, not identities or a private key. Aggregates include paired family differences and fixed synthetic seeds where present; these are result data, not real-person records. No actual generated identity key, key hash receipt or private lock content is included. Research code necessarily retains generic key-handling and guard logic; static test literals are synthetic fixtures. This is a reviewed scope, not a promise that pattern scanning proves absence of every possible secret.

The exact-copy files have matching source/output SHA-256 values in [provenance.json](../provenance.json). Adapted and generated files identify their sources and transformations separately. A hash validates byte correspondence against a known source; it does not itself prove authorship, licensing, historical execution or a prior timestamp. Public readers cannot resolve the private source commits from this new repository. No Git history is imported.

Some unchanged freeze paths require the excluded original instruction document, and raw auditors require excluded runs/locks. Topology evaluation freezing additionally enforces the elapsed2026-11-08 date gate; the origin's one-evaluation/one-reproduction attempts were used. A new clone's missing records do not remove these provenance restrictions. No guards were edited and no replacement key/lock/attempt state was generated.
